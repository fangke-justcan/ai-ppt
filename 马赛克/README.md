# Celestia Glass — 本地复刻（笔刷版）

并在其基础上加入了一套**实时笔刷与参数面板**，可以直接在界面上修改画面效果。

## 运行方式

**方式一（最简单）**：直接双击 `index.html`，在浏览器中打开即可
（此时使用页面内置的着色器源码副本）。

**方式二（推荐用于改代码）**：启动任意静态服务器后访问，着色器会从
`shaders/` 目录实时加载，改完保存、刷新即见效果：

```bash
# 任选其一
python serve.py            # 推荐：自带禁用缓存，改完刷新即见最新
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

> 需要 WebGL2 支持（Chrome / Edge / Firefox / Safari 16+ 均可）。

## 曲线句柄（Illustrator 式）

勾选"显示曲线句柄"后，画布上会直接叠加两组可拖拽的样条锚点：

- **金色句柄 — 太阳光线脊线**：8 条光线共用一条母曲线（着色器内 moda 折叠），
  拖动任意锚点，所有光线同步弯折；
- **蓝色句柄 — 花纹边界轮廓**：拖动锚点直接改写背景条纹边界曲线的走向。

句柄用 Catmull-Rom 样条插值，默认锚点位置还原原作曲线（`sin` 脊线 / 直线边界），
「重置曲线」一键恢复。**笔刷为「关」时，按住画面任意位置拖拽都会自动抓取最近的
曲线锚点**（零死区，不存在按空）；选用任一笔刷后，拖拽变为笔刷绘制（句柄圆点
仍可直接抓取）。

## 笔刷与面板

右侧控制面板中先选择一种笔刷，然后在画面上**按住拖拽**即可：

| 笔刷 | 效果 |
| --- | --- |
| 扭曲 | 沿拖拽方向推挤玻璃格，像在湿玻璃上抹动（画面整体） |
| 漩涡 | 按住原地旋转，把马赛克拧出漩涡 |
| 膨胀 | 从笔刷中心向外推挤，放大局部 |
| 上色 | 给笔刷范围内的玻璃叠加局部色相偏移（配合"上色色相"滑杆） |
| 花纹 | 直接弯曲背景条纹的边界曲线——笔划往哪边抹，条纹就往哪边弯 |
| 填色 | 按 Voronoi 玻璃块整块填充选中颜色（"填色颜色"色板随调色板联动） |
| 太阳形变 | 直接弯曲太阳的曲线：光线、轮廓跟着笔划弯折，始终保持锐利金色玻璃渲染 |
| 擦除 | 把笔刷范围内的所有笔刷效果一次性还原（"清空笔刷"按钮一键全清） |

参数面板（全部实时生效）：

- **玻璃马赛克**：格子大小、格线粗细、格子抖动（0 = 整齐蜂窝状）、玻璃高光
- **背景**：波浪起伏、条纹宽度，以及 4 套调色板预设（原始 / 晚霞 / 海洋 / 糖果）
- **太阳与翅膀**：太阳大小、光线数量（3–16）、光线波动、上下浮动、翅膀展开
- **全局**：整体色相偏移、动画速度
- **保存图片**：一键导出当前画面 PNG；**重置参数**恢复到与原作一致的效果

键盘：`空格` 暂停/继续，`R` 重置时间轴，`F` 全屏，`H` 收起/展开面板。

## 实现说明

- 运行器按 Shadertoy 的约定包装着色器代码，提供标准 uniforms：
  `iResolution`、`iTime`、`iTimeDelta`、`iFrame`、`iMouse`、`iDate`、
  `iChannelTime`、`iChannelResolution`、`iSampleRate`。
- 笔刷版着色器（`celestia_glass_brush.frag`）把原作中的硬编码常量参数化为 uniforms，
  并新增三张**笔刷场纹理**（屏幕空间映射的 ping-pong FBO，JavaScript 端按帧叠加笔划）：
  - 场一：RG 通道存全局扭曲位移、B 通道存局部色相 —— 驱动扭曲/漩涡/膨胀/上色笔刷；
  - 场二：RG 通道存背景花纹变形、BA 通道存整块填色（色号+强度）—— 驱动花纹/填色笔刷；
  - 场三：RG 通道存太阳变形 —— 驱动太阳形变笔刷。
  变形场直接弯曲图案的**参数曲线**（条纹边界、太阳光线与轮廓），形状始终按
  SDF 矢量渲染、保持锐利；填色按 Voronoi 玻璃块的**特征点采样**，保证整块玻璃一起变色。
- 笔刷版所有参数取默认值时与原作逐像素一致；原作源码文件原样保留在
  `shaders/celestia_glass.frag`，可供对照或放回 Shadertoy 运行。
