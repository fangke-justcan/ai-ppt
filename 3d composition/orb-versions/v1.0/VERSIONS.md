# 版本馆（VERSIONS）

每个重大变化 = 一个 git 标签版本。命令行查看全部版本：`git tag -n`

## 如何打开某个版本

1. **双击 `versions.bat`** → 显示版本列表 → 输入编号回车 → 自动在 `../orb-versions/<标签>/`
   生成该版本的独立快照，并在浏览器打开（端口 8943 起，与主项目 8942 互不干扰）
2. **对 ZCode 说**："打开 v1.0 版本" / "列出版本"
3. **手动命令**：
   ```bash
   git worktree add ../orb-versions/v1.0 v1.0
   cd ../orb-versions/v1.0 && node server.js 8943
   ```

快照目录是只读参观用的副本，直接删除 `orb-versions/` 即可清理，主项目不受影响。

## 版本约定（打新版本三步）

```bash
git tag -a v1.1 -m "一句话说明这个版本做了什么"
git -c http.proxy=http://127.0.0.1:10080 push origin main --tags
# 同时把新版本加进上面的表格
```

版本号习惯：`v1.x` 功能新增 / `v2.0` 大改或破坏性变化 / 临时实验不打标签，用分支。
