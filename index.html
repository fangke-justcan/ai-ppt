Workshop Exhibition
小组任务

每个小组做一个展示网页

像本课程的 PPT 一样 ——

在一个网页中融合三个项目，全部可以实时操作

写出小组整体的情绪目标

加上你们的作品介绍

做的方法步骤

1

每个人的项目上传 GitHub，并且让 AI 出 GitHub 链接

2

小组代表建立一个文件夹，给 AI 三个项目的 GitHub 链接，并让 AI 在这个文件夹中克隆这几个项目

3

让 AI 基于三个项目生成展示网页，网页细节由小组给出提示词

4

测试：某个成员的项目做一个更新并推送到 GitHub 线上后，看小组网页能否拉取最新并更新 —— 如果可以，整个流程就完成了
